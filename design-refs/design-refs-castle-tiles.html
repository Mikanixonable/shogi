囲いタイル 幅詰めの案（実寸）

0 いまA ぴったり札B 細格子C 駒札比較

左ドックの囲いカードは「サムネイルがカードより細い」まま横に伸びています。サムネイル（ミニ盤）は高さ 50px 固定・幅はアスペクト比任せで、4x3窓は約57px・5x3窓は約71pxしか描かれません。一方カードは minmax(100px,1fr) の格子で実効約105pxあるので、1枚あたり約48px（46%）が左右の余白です。カード幅をサムネイルに合わせる3案を、実SVG・実寸の器（左ドック390px・中身約326px）で並べます。

  • 載せているUIは全案で同じ: 層タブ・戦略の絞り込み・並べ方・記号の凡例・系統ブロック（折りたたみ可）・◎△✕・基本の落款・選択中・既定値の点線・駒の見出し。
  • ◎△✕・選択中・既定値は見本のための仮の状態です。系統ブロックは折りたためます。
  • サムネイルは実アプリの miniBoardSVG（玉側の隅の窓、最小4筋x3段）。中住まい型・右玉型だけ5x3窓で少し横長です。

0いま — サムネより横に広いカード

基準。カードは格子いっぱい（最小100px、実効約105px）に伸び、サムネイルは高さ50pxの帯の中央に浮く。左右の余白（斜線部）が1枚あたり約44pxあり、3列までしか並ばない。

居飛車穴熊
カード ≈105px（中身 ≈103px）
サムネ ≈57px（4x3窓・描画高さ47px）
左右の余白 ≈48px（46%）
5x3窓（中住まい・右玉）は ≈71px。それでも30px超余る。

囲いの一覧（居飛車・系統別）

◎相性がよい　△苦手　✕両立しない

読みどころ

  • サムネの両脇の余白が、カードごとに無駄な面積を作っている。
  • 系統色の下線はカード全幅に引かれるので、サムネとズレて見える。
  • 1行に3枚。一覧性は低い。

Aサムネぴったり札 推奨

カード幅をサムネの描画幅（--tw）＋罫線分に限る。絵と枠が一致するので締まって見え、系統色の下線もサムネとぴったり重なる。横並びは flex-wrap（窓ごとに幅が違うので右端は不揃いになる）。名前はサムネ幅の中で折り返す。

囲いの一覧（居飛車・系統別）

◎相性がよい　△苦手　✕両立しない

変わるところ

  • .dk-cards: grid → display:flex; flex-wrap:wrap; gap:8px 6px
  • .dk-card: width:calc(var(--tw) + 2px)（--tw は JS が窓から算出）
  • .dk-card .nm: overflow-wrap:anywhere で折り返し許可

よい点

  • 絵と枠が一致し、カードが「サムネの額縁」として読める。
  • 5x3窓（中住まい・右玉）も自然に広い札（約73px）になる。
  • 状態の印（朱枠・✓・落款・点線）はそのまま乗る。

気をつけるところ

  • 行の右端は不揃い（57px札と71px札が混ざる）。詰め込みは5枚/行ほど。
  • 長い名（居飛車穴熊・天守閣美濃など6字以上）は2行に折り返す。
  • JS: dock-grids.js の card() で K.miniWindow の窓から --tw を出して style に渡す（1行＋CSS数行）。

B細格子 — 格子のまま5列へ

格子レイアウトは残し、列の最小幅をサムネの最小描画幅に合わせる（minmax(58px,1fr) → 中身326pxで5列＝約61px）。右端は揃うが、5x3窓のサムネはカードの中で少し縮む（欠けはしない）。名前は少し小さく＋折り返し。

囲いの一覧（居飛車・系統別）

◎相性がよい　△苦手　✕両立しない

変わるところ

  • .dk-cards: minmax(100px,1fr) → minmax(58px,1fr)（1行の変更）
  • .dk-card .nm: 10.5px＋折り返し許可

よい点

  • 変更が最も小さい。JSは無変更。
  • 行列が揃い、1行に5枚で一覧性が最も高い。

気をつけるところ

  • 5x3窓は約61px幅の列に収まるよう縮む（高さも約40pxに）。4x3窓より一回り小さく見える。
  • 「カードに対しサムネが小さい」の構図自体は残る（余白は数pxに縮むだけ）。

C駒札 — カードの面を捨てる

もっとも軽い案。カードの枠と面を捨て、サムネ自体が札になる（罫線はサムネの縁だけ、系統色の下線はそのまま）。名前は明朝で下に添える。選択中の朱枠・✕の破線・落款はサムネの縁に乗せる。幅の決め方はAと同じ（--tw）。

囲いの一覧（居飛車・系統別）

◎相性がよい　△苦手　✕両立しない

変わるところ

  • .dk-card: 枠・背景・余白を捨て、width:calc(var(--tw) + 2px)
  • .dk-card .thumb: 罫線と系統色の下線はサムネへ移す
  • 状態の印（朱枠・破線・落款）もサムネの縁に掛ける

よい点

  • 余白がほぼゼロになり、最もスリム・軽い見た目。
  • 和紙の地に駒札が並ぶ、テーマに合った絵。

気をつけるところ

  • 押せる面（ボタン感）がサムネと名前だけになる。ホバーの持ち上げは残す。
  • ✕の破線枠がサムネに掛かるので、盤の絵と少し重なって見える。
