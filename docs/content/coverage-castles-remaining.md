## 1. 凡例と確認方法

- 優先度 A/B/C・適合度 ◎○△× はブリーフ §6 に従う
- 判定の語: **新規** = 独立エントリにする / **別名** = 既存エントリの aliases に入れる / **崩れ形・変種** = 既存エントリの note・desc で触れる / **見送り** = 確定できず、または図鑑の対象外
- 座標は先手の絶対座標（筋＝右から左へ1〜9、段＝後手側から先手側へ1〜9）。Wikipedia の局面図は wikitext の `{{Shogi diagram}}` を機械変換して読み取った（左端の列が9筋、最上段が1段）
- 「確認済み」は、ページの本文または局面図を実際に取得して読んだもののみ。取得方法は §6 の出典表に記す
- 補助資料として GitHub の bioshogi（将棋ウォーズ棋譜の囲い判定に使われる Ruby ライブラリ）の判定定義を参照した。個人開発の資料なので、**これ単独では「実在」の根拠にしない**（Wikipedia・shougi.jp・書籍など2件目の資料があるときだけ採用する）
