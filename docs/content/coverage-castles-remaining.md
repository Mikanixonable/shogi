書式: 判定 / 優先度 / 適合度 → 実在 → 形 → 吸収の可否 → 系統・from 案。出典の略号は §6 を参照（`wj-`=Wikipedia日本語版、`we-`=英語版、`jsf-`=日本将棋連盟コラム、`bio`=bioshogi）。

### 3-1. 旧計画の積み残し（最優先で決着）

#### C1 トーチカ — **新規（独立エントリにする）** / 優先度 B / 適合度 ◎

- **独立させるべきか: 独立させる。** 現行の `millennium` は 6七金型（玉89 銀88 銀79 金78 金67 桂77）で、トーチカは別の駒配置だから。注記だけでは盤上に出せない
- 実在: [wj-millennium] 本文「別名、三浦囲い、かまくら囲い、蒲鉾囲い（島朗『島ノート 振り飛車編』2002年で「カマボコ囲い」）、トーチカなどとも呼ばれるが、そのうち右図の6六角型を特に『トーチカ』と呼んでいる」。注に『三浦&阿部健の居飛車研究』（マイナビ将棋BOOKS、2015年）、高橋道雄『固めてドカン！ 対四間飛車ミレニアム＆トーチカ戦法』（マイナビ将棋BOOKS、2020年）を例に挙げる（書誌は Wikipedia の記述を転記。書籍そのものは未確認）。所司和晴『四間飛車道場 第一巻 ミレニアム』（2001年）は6六角型と6七金型に区分する、とも書かれている
- 形（先手）: **玉89 銀88 金79 金78 銀68 桂77 角66**（歩67 歩76 歩97 歩87）。[wj-millennium] の局面図「6六角型・トーチカ」と、同記事の手順図 fig.1-6（完成図）が一致。[we-castle] の「Millennium Variant 5」（玉89 金79 金78 銀88 銀68 桂77）も一致。完成図は先手20駒がそろう: 玉89 金79 金78 銀88 銀68 桂29 桂77 香99 香19 飛28 角66 歩97 歩87 歩67 歩47 歩37 歩17 歩76 歩56 歩25
- 6七金型との違い: 金が79・78、銀が88・68（6七金型は銀88・銀79・金78・金67）。6筋の歩は67に残し、角が66へ出て桂77を跳ねる。Wikipedia の手順解説は「▲6六角（地下鉄飛車と同じ出だし。桂馬を跳ねられるよう6六まで出る）→▲7七桂（8九を空け、後手左銀の玉頭銀進出を牽制）→▲8九玉」と説明する
- 吸収の可否: 別名として吸収するのは不適。`millennium` の aliases にはトーチカを入れず、desc の「6六角型はトーチカとも呼ばれる」を「6六角型は別項『トーチカ』」に直す。`millennium` 側の別名候補は §5
- 系統・from: family `yagura` / subtype `millennium`（既存。新設不要）。from は付けない（`millennium` も付いていない。駒の動きで一方から他方へは組めない）
- データ下書き: §4-1

#### C2 升田美濃 — **新規** / 優先度 B / 適合度 ◎

- 実在: [wj-hidarimino] §囲い方「升田美濃」本文＋局面図「升田美濃」。「角道不突美濃のように王将の位置は▲7九玉型に構えるが、角道を開けて角行は居角かもしくは▲7七角型に構える。相居飛車戦で用いられ、1950年代初頭に木村義雄の相居飛車5筋交換型作戦に対抗するために升田幸三が編み出す」。注に『将棋囲い事典100+』（マイナビムック 将棋世界Special、2020年）を挙げる。同記事「居角左美濃急戦」の節も「対矢倉の居角左美濃は玉を△3一（先手なら7九）の位置、升田美濃と呼ばれる左美濃に収め、腰掛け銀と右四間飛車の形から速攻を仕掛ける」と書く。[bio] にも同名の判定がある（玉79 銀78 金69 金67 角77）
- 形（先手）: **玉79 銀78 金69 金67**（角77、歩96 歩87 歩76 歩66 歩56）。局面図は桂89・香99も含む。実戦図（[wj-hidarimino] 第3-1図「居角左美濃急戦」）では金67ではなく**金58・角88**の形で現れるので、note に両方を書く
- 左美濃との違い: 玉が8八ではなく7九、金が58ではなく67。角道は開けるが、5筋の歩は突かない。9七・1三への角筋（端の角の覗き）を避けられる、と同記事は述べる
- 吸収の可否: 吸収不可（玉の位置が違い、相居飛車での用途も違う）。**角道不突き左美濃**（玉79 銀78 金69 金58 角88）は兄弟形。§3-4 の「追加の発見」に回す
- 系統・from: family `mino` / subtype `hon`（既存で足りる。分けたければ `masuda` を新設）。**from: `hidarimino`**（玉88→79、金58→67の2手）
- データ下書き: §4-2

#### C3 金開き — **新規（C。アヒル囲いとは別形として）** / 優先度 C / 適合度 ◎

- 実在: [wj-kinbiraki] 本文「金開き（きんひらき）とは、将棋の陣形・囲いの一つ。中住まい陣形の一種。図の例のように金が左右に開くのでこの名がある。陣形の進展は単純で、先手の場合左金を7八金、右金を3八金と動かすだけである。玉は5八の地点に構える。このような構えは横歩取り青野流で頻繁に生じる」。[wj-kakoi]「相居飛車: その他: 金開き（アヒル囲い、大阪囲い）」
- 形（先手）: **玉58 金78 金38**。銀は初期位置の79・39のまま。局面図は玉58 金78 金38 銀79 銀39 桂89 桂29 香99 香19 飛26 角88 歩87 歩77 歩67 歩57 歩47 歩37 歩17 歩96
- **アヒル囲いとの関係（要注意）**: [wj-ahiru] は「別名は金開き」と書くが、アヒル囲いの図は金79・金39・銀68・銀48で、金開き記事の図（金78・金38・銀79・銀39）とは**別の配置**。同じ「金開き」の名が2形に使われている。さらに [wj-ahiru] は「滝下流金開き（浮雲戦法）はアヒルとは全く異なる戦法」とも断る。→ 既存の `ahiru` に「金開き」を別名として入れると、新規の金開きと衝突する。`ahiru` の別名は「御神酒指し」「大阪囲い」にとどめ、「金開き」は新規エントリの名前に使う（§5）
- 中住まいとの関係: `nakazumai`（玉58 金78 金38 銀48）の銀39→48を省いた手前の形。[wj-kinbiraki] も中住まいの一種とする。`nakazumai` の desc は既に「金は7八と3八に開き（金開き）」と書いている
- 系統・from: family `nakazumai`（既存）。from なし。任意で `nakazumai` の from を `kinbiraki` にすると発展ツリーがつながる（変更は開発者判断）
- データ下書き: §4-3
