## 3. 横断的な課題（重要度順）

  - 「大損しました（永瀬拓矢）」「まぐれ（羽生善治）」は、報じた記事が見つからず、誤帰属のおそれがあるので削除を推す

### 3-10. 相振り飛車が、戦法の側でほぼ空白（データで確認済み）
