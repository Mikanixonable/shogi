## 3. 横断提案

### 系統（family/subtype）の置き場所

- **kushikatsu の family=anaguma**: wj-kakoi では「その他」（端美濃/串カツ囲い）に列挙され穴熊系統ではないが、形は穴熊に近い（玉・香・桂・金銀の固め）。アプリ独自分類として anaguma/kushikatsu で妥当（subtype 修正適用済）。sj の一覧でも「居飛車その他」に分類されており、文献上はどちらとも —— 今のままでよい。
- **saikyou/ahiru/ichigo の family=quick**: sj の一覧では「居飛車その他」に分類（アヒルは「特殊・駒落ち」にも）。quick（簡易囲い）はアプリ独自の短手数まとめとして機能している。
- **ibisha-ginkananaguma の core 問題（再掲）**: sj は振り飛車側の図、we は金88型。金67は左銀冠系の発展として最も自然だが、資料間で前面の金の位置が揺れる珍形。他の候補形（金68型＝振り飛車反転、金88型＝we 変形）を別カードにするほどの資料の厚みはないので note で吸収（適用済）。

### 命名・表記

- 「総矢倉」「流線矢倉」「端玉銀冠（米長玉）」「田尻穴熊」などの命名はいずれも出典どおり。`ichigo` の表記揺れ（いちご/イチゴ/苺）は sj/we で「いちご囲い」「イチゴ囲い」と揺れる — 現行「いちご囲い」でよい。
- `oojun` の reading「おおじゅんがこい」、aliases 未設定だが「大盾」単独でも通じる — 問題なし。

### sj 図の取り扱い

- sj の囲い図は実戦例の切り出しで、端歩9六など中盤形の歩が混ざる。定義駒（玉・金・銀・桂・香・角）の一致を優先し、歩は定義部のみ照合する方針で今回も問題なかった。
- **sj-kushikatsu だけは図がデータと1枚違い**（金79 vs データ旧金67）だった — 他出典2件も金79だったためここだけ実修正。今後 sj の掲載図とタイトル・本文が食い違う場合は図を正とする。
