# 囲い記述 文献監査メモ（quality-castles）

作成: 2025年 文献照査（js/data/castles-ibisha.js 29件 + castles-furibisha.js 10件 = 全39エントリ）

判定凡例:
- **OK** … 引用文献（主に Wikipedia日本語版の該当記事・図）と一致
- **要出典** … 取得文献に直接の裏付けはないが、将棋的に妥当な記述
- **疑義** … 文献と齟齬の可能性がある（修正推奨）
- **誤り** … 取得した文献の記述と明確に矛盾

照合方法: sources.js の各 ref URL のうち Wikipedia日本語版（一次ソース）を実際に取得し、記事本文と掲載の駒配置図を突合した。shougi.jp・将棋上達塾・マイナビ・JSF(web.archive) 等の二次ソースは、同一主張が Wikipedia の記述で確認できたため個別取得は割愛（未取得の旨を各所に明記）。英語版 Wikipedia も未個別取得（配置主張は日本語版で確認済み）。

### doiyagura（土居矢倉）… 誤り×2

- **人名**
  - 現行: `desc` …「土居市之助名誉名人が好んで用いたことに由来する」
  - 案: 「**土居市太郎**名誉名人が得意としたことに由来する」
  - 理由: 人名誤り。Wikipedia「土居矢倉」（矢倉囲い記事内節）は「**土居市太郎**が得意としたことから土居矢倉と呼ばれる」と明記。将棋史の人物は土居市太郎（実力制第四代名人、名誉名人）。「土居市之助」は誤記。
  - 根拠: wj-doiyagura（→矢倉囲い#土居矢倉）

- **金の左右**
  - 現行: `desc` …「金矢倉より手数を省け、**左金は8段目に残して**中央を広くカバーする」
  - 案: 「金矢倉より手数を省け、**右金を5八（8段目）に残して**中央を広くカバーする」
  - 理由: Wikipediaは「7七銀、7八玉に加え、6七に**左金**を上げる囲い」「右側の金を自由に使える」。つまり6七に上がるのが左金、8段目(5八)に残るのは右金で、現行は左右が逆。core `'玉78 銀77 金67 金58'` 自体は文献の基本図と一致するので配置は正しい。
  - 根拠: wj-doiyagura（基本形図: 金6七・金5八）

### kinmusou（金無双）… 疑義（強い方向が文献と逆）

- 現行: `desc` …「横からの攻めに強く、上部への備えもある」、`pros[0]` …「飛車など横からの攻めに強い」、`cons[0]` …「玉頭（3筋・2筋の上部）はやや薄い」
- 案:
  - desc: 「…玉3八・銀2八で固める。**上部（1・2筋）からの攻めに強く**、相振り飛車の代表的な囲い[[wj-kinmusou|sj-kinmusou]]。」

### gangi（雁木囲い（旧型））… 疑義（命名由来が俗説）

- 現行: `desc` …「銀の並びが雪国の『雁木（がんぎ）』に似ていることから」
- 案: 「駒が**階段状に連なる様子**を、雁の群れが斜めに連なって飛ぶ姿に見立てた『雁木』に由来する。雪国の雁木造（雪避けのひさし）に由来するという説も広まったが、これは誤解とされる[[wj-gangi]]」
- 理由: Wikipedia「雁木囲い」は「階段状の構造物のことを鳥の雁の群れが斜めにジグザグに連なって飛ぶ様子に見立てて『雁木』といい、これが雁木戦法の由来」とし、「雪避けのひさし（雁木造）がその由来であるという**誤解が広まっている**」（英語名Snowroofもこの誤解に基づく）と明記。現行は誤解とされる側の由来説をそのまま採用している。
- 根拠: wj-gangi
- 併記（要出典・軽微）: `tags` の「江戸時代からある」は、本来の雁木（対振り引き角戦法・檜垣是安）が江戸時代の一方、二枚銀雁木として流行したのは昭和戦前期（木村義雄「木村不敗の陣」）。檜垣是安も類似形を江戸時代に指していた記述があるため全くの誤りではないが、タグだけ見ると旧型雁木自体が江戸発祥のように読める。`tags`→「木村不敗の陣」または note 追記を推奨。

### kimuramino（木村美濃）… 疑義（命名由来）

- 現行: `desc` …「木村義雄十四世名人が**中飛車で好んで用いた**ことに由来する」
- 案: 「木村義雄十四世名人が**香落ち戦で多用した**囲いで、平手戦ではツノ銀中飛車戦法などとの相性がよい[[wj-kimuramino|sj-kimuramino]]」
- 理由: Wikipedia 美濃囲い記事は「木村義雄が**香落ち戦**で多用した囲いが木村美濃。平手戦でも**ツノ銀中飛車戦法**や雁木戦との相性が良い」と記述。「中飛車で好んで用いた」とは書いていない。ただし「中飛車では必然的に片美濃になる」（金が使えない）事実は記事にもあり、desc 後半「中飛車の陣形と両立しやすい」は OK。由来部分のみ要修正。なお同記事は『将棋世界』1947年2・3月号「駒組名称募集」で命名されたとも記す。

### ginyagura（銀矢倉）… 疑義（比較表現）

- 現行: `desc` …「銀は上方向への利きが強いので**上部・玉頭への耐性は金矢倉以上**」、`pros[1]` …「6七銀が5六・7六を押さえ」
- 案: 「7六の地点への攻めに強く、**7八の金に6七の銀が利いている**のが特徴（金矢倉の7八金は玉1枚の支え）[[wj-ginyagura]]」
- 理由: Wikipedia「銀矢倉」節の特徴は「7六の地点への攻めに強いことと、7八の金に6七の銀が利いていること」で、「上部耐性が金矢倉以上」とは書いていない。銀は真横（5七・7七）には利かず、むしろ側面は金矢倉より薄い。「6八方面が弱点」自体は銀が真下に利かない事実として妥当（要出典扱いで残置可）。
- 根拠: wj-ginyagura（→矢倉囲い#銀矢倉）

## 補足: taxonomy.js の点検結果

- `funa`（舟囲い型）…「玉が7八。金銀が玉の横から下へ広がる」は文献の舟囲い系と整合。subtypes「基本形（7九銀・6八銀・5七銀）」も Wikipedia の発展形区分（7九銀型・6八銀型・5七銀左右型）と整合。OK。
- `yagura`（矢倉型）…「逆L字」表現は独自分類として妥当。subtype `millennium` を矢倉系に入れているが、文献では対振り飛車用の独立囲い（かまくら・トーチカ系）。アプリ独自分類と明記はあるが、形の近さ（一段玉・桂7七）は菊水との共通項として正しい。**要注記**: millennium subtype 名の「（一段玉・金銀4枚）」は正しい（桂含む6駒構成）。
- `gangi`（雁木型）…「銀が玉の前や横に並んで壁を作る」は二枚銀雁木の描写としてOK。kani・kabuto を雁木型に分類するのはアプリ独自（文献上カニ＝矢倉の子供、兜＝矢倉系統）。refFamily で注記済みなので許容範囲。
- `anaguma`…「玉を隅にもぐらせ、香で蓋をする」は文献の「香を上げて空いた隅に玉を入れ、銀でフタ」と整合。subtype `yonmai`（松尾流・ビッグ4）は金銀4枚で整合。`ginkan`（銀冠型）は銀冠穴熊（銀2七）と整合。OK。
- `mino`…「玉・銀・金が斜めにつながる」OK。subtype `ginmino`（「銀美濃系」）に yonmaimino（四枚美濃）と diamond（ダイヤモンド美濃）が入るのは緩い命名（文献の「銀美濃」は左金の代わりに左銀が参加する別形で、四枚美濃≠銀美濃）。**軽微な命名のずれ**として注記推奨。diamond は「金銀の連携の形から」ダイヤモンドと呼ばれ文献上は銀美濃の一種と言いにくいが許容。
- `itidan`（一段玉型）…「玉が8九に座り」は菊水・ミレニアム・一段玉型左美濃と整合。OK。
- `nakazumai`…「玉が5〜6筋の中央に留まり」は文献（5八玉）と整合。OK。
- `chudan`…「自陣寄りの中段（主に6段目）」は文献（四五六段目、先手は六段目）と整合。OK。
- `kinmusou`…「金2枚が横に並び、玉と銀がその前に座る（相振りの右辺）」は文献（玉3八・金4八/5八・銀2八、壁銀形）と整合。OK。
- `migigyoku`…「玉を飛車側の右辺へ寄せ、金銀が左と正面を囲む」は文献の角換わり右玉図と整合。OK。
