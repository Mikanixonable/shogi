照査方法: 各エントリの `desc/pros/cons/pairings/note/context/senkei` の事実的主張を、引用 `[[ref-id]]` 先（`sources.js` の URL。主に Wikipedia日本語版）を webfetch で実際に取得し照合。未取得ページは同トピックの専門記事で代替照査した。

判定: OK = 文献と整合 / 要出典 = 主張自体は妥当そうだが引用文献に直接の裏付けがない / 疑義 = 文献記述と一部食い違う・表現が曖昧 / 誤り = 文献記述と明白に矛盾。

### E. yamada-jouseki（山田定跡）— 概ねOK、1点疑義

- **確認済み**: 「山田道美が大山康晴の四間飛車打倒を目指して定跡化」「1957年から雑誌『近代将棋』に講座として発表」— Wikipedia『山田定跡』に逐語確認。「先に▲4六銀とすると△4五歩で失敗」— 同記事に「単に▲4六銀-▲3五歩と手順前後すると、△4五歩の常用手段で反撃されて失敗する」あり。note OK。
- **疑義（pros）**: 「先手後手どちらの四間飛車にも対応した定跡が整備されている」— 山田定跡記事には「先手四間飛車に対する斜め棒銀」の節があり後手番の類型はあるが、鷺宮定跡記事には「そもそも四間飛車側が先手の場合、通常の駒組進行で両方の歩が突く状態になるため、**山田定跡は後手番では指すことができない**」と明記。「先手後手どちらにも対応」は強すぎる。修正案: 「対後手四間飛車が本筋で、先手四間飛車に対する類型の斜め棒銀手順も文献に残る[[wj-yamada]]」。

## 補足: task 点検項目への回答まとめ

- 腰掛け銀の定義 = ▲5六銀＋▲5七歩型（「歩越し銀」）。「3五歩持ち」は早繰り銀・斜め棒銀系の突き捨てで、腰掛け銀はむしろ「5筋を突かない」が本手。現行記述 OK。
- 早繰り銀の系統 = 右銀3七→4六（▲3六銀→4五ではない）。矢倉・角換わり・相掛かり（中原流）の区別は現行 context と一致。
- 超速▲3七銀の開発者 = **星野良生**（奨励会三段・2010年度升田賞）。佐藤康光は名手▲5七玉で知られる使い手。
- 4六銀左戦法の定義 = 対四間飛車（3二銀・4三銀型）の舟囲い急戦・斜め棒銀。対ゴキゲンは文献になし → ②A 修正。
- 山田定跡 = 山田道美考案・1957年『近代将棋』発表（確認）。鷺宮定跡 = 青野照市創案・米長邦雄が広めた（対象外エントリだが現行 desc と一致）。
- ひねり飛車 = 相掛かりの居飛車戦法（▲2六飛→3六飛→左翼転換）。「対振り・角道不開」は文献と異なる。棒銀との区別は「飛車の転換」vs「銀の繰り出し」で現行どおり。
- 矢倉中飛車 = 居飛車に分類される急戦矢倉（主に後手）。現行 OK。
- 右四間飛車 = 先手4筋に振る居飛車戦法。現行 OK。
- 袖飛車 = 3筋（後手7筋）への「一つ振り」。現行 OK。
- 雀刺し = 矢倉系の1筋集中攻め（▲1七香▲1八飛▲2五桂▲6八or7九角→1三）。「3筋歩3五→3四の形」はこの記法では確認できず、定義は飛び道具集中型として現行どおりで正しい。
- 鬼殺し = 先手の奇襲（▲7七桂→7五歩交換→6五桂→5五角）。一手損角換わり系ではない。
- 筋違い角 = 角換わり序盤（△2二銀に▲7八金とせず）から成立。現行 OK。
- 嬉野流 = アマの嬉野宏明開発・天野貴元2015棋書・対振りでは鳥刺しに合流または相振りに。現行 OK。
- メイドシステム = 押木ゆい考案・引き角系総合戦法。現行 OK。
- 森下システム = 森下卓開発・**相矢倉**の思想（対振りの引き角+左美濃は別物＝飯島流系）。現行 OK。
- 鳥刺しの起源 = 左香落ち将棋（四宮金吾説・大橋宗英説）。現行 OK。
- 4五歩早仕掛け = 対振り飛車の舟囲い急戦（雁木対策ではない）。現行の「相掛かり」は誤り → ②B 修正。
- カニカニ銀 = 児玉孝一考案の急戦矢倉（居玉・玉金不動）。現行 OK。
