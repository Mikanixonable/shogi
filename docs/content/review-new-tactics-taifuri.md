## 1. 要約

9件すべて照合完了。判定は 🟢3件（saginomiya・kamaitachi・migigyoku-senpou）・🟡6件（kinmino・gyokutou-kuraidori・ibisha-gosuji-kuraidori・chikatetsubisya・boukin・pacman-44fu）・🔴なし。

- **主な問題は `pieces` のずれ**: 4件（gyokutou・gosuji・chikatetsubisya・boukin）が出典の代表図と異なる創出/途中形の配置だった。いずれも Wikipedia `{{Shogi diagram}}` の代表図へ差し替えて解決（各修正版は初期配置からの指し手を検証済み）。
- **kinmino**: 出典2件が囲い解説で同名囲い `ibisha-kinmino` が既存のため、案A（戦法を削除して囲いに統合）を適用。
- **pacman-44fu**: 後手専用戦法を「180度反転した先手図」で表すモデルは妥当だが、図の歩76はモデルと矛盾するため歩77に修正。
- **kamaitachi / migigyoku-senpou**: 事実関係は正確。かまいたちは sj の基本形図と駒配置が完全一致。右玉は囲い `migigyoku` の正規化と整合。出典追加（wj-eishunryu / wj-migigyoku）のみ。
- 全体的に sj-*（将棋研究）の解説文と desc/pros/cons の食い違いはなく、戦法の定義・狙い・長短は概ね正確。欠落は Wikipedia 出典の未参照が主だった（wj-gyokutou・wj-chikatetsubisya・wj-boukin・wj-eishunryu を sources.js に新規登録）。

## 3. 周期表への置き方についての横断提案

- **位取り系の並置**: `gyokutou-kuraidori`（銀76・7筋位取り）と `ibisha-gosuji-kuraidori`（銀56・5筋位取り）は同じ ibisha-silver 行で lead.square が 76/56 と分かれるため、銀の筋の行で自然に並ぶ。どちらも図を出典の代表形へ差し替え済み。
- **棒金の lead を 金27 に変えた点**: Wikipedia 基本図（金27+歩26）に揃えた関係で lead.square が 26→27 になった。`ibisha-kin` 行の他エントリと square が衝突しないことは確認済み（バリデータも lead.square と route 末端・pieces の整合を検査済み）。棒金が本来「金を2六まで進める」戦法であることは desc に残るため、将来「2六まで出た完成図」に戻す選択肢もある（その場合は歩26の扱いを要検討）。
- **pacman-44fu（後手専用戦法）の扱い**: 現行は「後手局面を180度反転して先手図にする」方式で、note にその旨を明記して ibisha-fu（歩の筋）に置いている。駒棚が全件先手視点のデータモデルなのでこの方式は一貫しており、lead=歩で family=ibisha-fu とも整合する。ただし実際は後手が4筋へ飛車を回す振り飛車的な戦法なので、将来「後手番戦法」の区分や `variantOf`/対抗関係の表現ができたら見直し候補（現状では context「▲7六歩への後手番の応手」と tags「後手番」で判別可能）。なお againstTactic へ「対象となる相手戦法」を張る枠組みはあるが、相手は特定の戦法ではなく「▲7六歩とした先手全般」なので未設定が妥当。
- **英春流の体系**: `kamaitachi` は対振り飛車で5筋位取り型・対居飛車で菊水矢倉型へ発展する総合戦法。`ibisha-gosuji-kuraidori` との親子（variantOf）は lead.square が 57/56 で異なり張れない。関連づけたい場合は note 相互参照に留めた（sj-kamaitachi が明記する関係）。
- **地下鉄飛車と右玉**: `chikatetsubisya` は対右玉・対振り飛車穴熊の攻め、`migigyoku-senpou`（右玉）はその標的。againstTactic の双方向リンク（chikatetsubisya→migigyoku-senpou:good、右玉側→chikatetsubisya:ng）は出典（sj-migigyoku が対策として明記）があって張れるが、「戦法 vs 囲い（migigyoku）」の対応ではなく戦法同士の対応なので、登録するなら `migigyoku-senpou` 側から ng で返す形が筋【要確認】。今回は加えていない。
- **後手番戦法は他にもある**: `yonenaga-kyusen`（米長流急戦矢倉）も元は後手番で、すでに先手図+note の同型で登録済み（「後手番発祥のため先手版の図は要検証」との注記つき）。pacman-44fu も同じ扱いなので、後手番戦法の note 表現を統一するとよい。
