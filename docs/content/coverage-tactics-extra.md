## 1. 相振り飛車（最大の空白）

### 1-1. 現状の空白（実測）

`js/data/tactics.js`（振り飛車の飛車の筋 21件）を node で集計した結果と、`Kakoi.compat.judge`（相手=振り飛車）の実測。

- `against.furibisha`（相振りでの適性）を持つのは **九間飛車の1件だけ**。残り20件は `against.ibisha` のみで、相振りでは常に「ok」扱いになる（`matchup.tacticFit` の既定）。
- 相振りの囲い（金無双・右矢倉・大住囲い・相振り穴熊4八金型・中飛車左穴熊）を `pairings` に持つ戦法は **0件**。`context` が相振りに触れるのも九間飛車だけ。

### 1-2. 相振りの戦型：指し方の要点（出典付き）

相振りは「飛車を振る筋の組み合わせ」で多様になり、囲いは自由。杉本昌隆は「角のいないほうにお互い玉を囲う」、藤井猛は「囲いは相手を見てから決める」と述べる（[[wj-aifuribisha]]の囲いの節）。以下は ja.wikipedia「相振り飛車」（WebFetch で確認済み）と、日本将棋連盟コラム「玉の囲い方」（一瀬浩司。Web Archive を curl で本文確認）による。

| 戦型 | 指し方の要点 | 相性のよい囲い | 出典 |
|---|---|---|---|
| 向かい飛車（飛88） | 先手側の採用が多く最人気。▲6六歩と角道を止め、▲6七銀・▲7七角・▲8八飛と組む。理想形は▲8六飛-7七桂-6六角（浮き飛車）。現在は引き飛車が主流。矢倉戦同様に千日手の危険がある | 金無双（入門者向け）・右矢倉（上部に厚い）・美濃（コラムの基本例）。なお「相手が向かい飛車だと自分の美濃は2筋の攻めに弱い」（藤井猛）は相手の戦法との相性の話 | wj-aifuribisha / jsf-kakoi-aifuri-kinmusou / jsf-kakoi-aifuri-yagura |
| 三間飛車（飛78・飛76） | 後手側の採用が多い代表格。金無双主流時代は石田流（浮き飛車）が一般的。右矢倉相手には相性が悪く、現在は引き飛車が主流。近年は穴熊との組み合わせ（戸辺流）が多い | 美濃（三間には相性良し）・穴熊・金美濃 | wj-aifuribisha |
| 四間飛車（飛68） | 採用はもともと少ない（浮き飛車にしにくい等）。ただし右矢倉相手には相性が良く、囲いを確認してから振り直す例が多い。角交換系の流行で一時人気になった | 矢倉への対抗として・美濃 | wj-aifuribisha |
| 中飛車（飛58・飛56） | 戦型ランクは中飛車＜四間＜三間＜向かい（鈴木大介）。相手玉から遠く分断されやすいと言われてきたが、中飛車左穴熊の発見で見直された。相中飛車は杉本昌隆の定跡書があり、囲いは相美濃が圧倒的 | 中飛車左穴熊（浮き飛車5六で横利き）・美濃・金美濃。金無双は飛車と金が5八で重なるので不可 | wj-aifuribisha / jsf-kakoi115 |
| 九間飛車（飛98） | 相振りの端攻めの専用戦法（収録済み） | 美濃・穴熊 | 既存 kyukenbisha |

- 囲いの相性は三すくみ（久保利明）: 穴熊には金無双、金無双には矢倉、矢倉には穴熊が良いとされる（[[wj-aifuribisha]]）。
- 公式戦の局数: 2000年度65局→2010年度151局（全公式戦約2,400局の約6%）。2010年代以降は▲7六歩△3四歩▲6六歩の出だしが主流から外れ、3手目▲7五歩（早石田志向）や▲6八飛（角道オープン四間飛車）から相振りへ誘導する指し方も増えた（[[wj-aifuribisha]]）。
- 日本将棋連盟コラム（一瀬浩司）が示す先手の組み方（向かい飛車）。共通の6手: `▲7六歩 ▲6六歩 ▲6八銀 ▲6七銀 ▲7七角 ▲8八飛`（=ja.wikipedia の「相振り飛車の最序盤の例」の図と一致）。続き: 金無双 `▲4八玉 ▲3八玉 ▲5八金左 ▲1六歩 ▲4八金上 ▲2八銀`／右矢倉 `▲4八玉 ▲3八銀 ▲3六歩 ▲3七銀 ▲3八金 ▲5八金 ▲3九玉 ▲4六歩 ▲4七金左 ▲2八玉`／美濃 `▲4八玉 ▲5八金左 ▲3八銀 ▲3九玉`。金無双では「端は突いたほうがよい」（銀の守りがあるため）、美濃・穴熊では端攻めを警戒して端歩を突かない場合が多い、とある。
- 相振りの端攻め: 穴熊相手には端攻めという手堅い攻めがある（藤井猛。同時に自陣は端攻めされない組み立てが要る）（[[wj-aifuribisha]]）。専用戦法は九間飛車（収録済み）。盤上の表現は囲いの `attacks`（id: hashi）が既にあるので、**新規の戦法エントリは不要**（相振り用の端攻めを足すなら手筋 TESUJI 側。図の出典が未確認なので今回は下書きなし）。

### 1-4. 組み込み方：周期表・pairings・COMBOS

**結論: 相振りは「戦法を増やす」より「既存の振り飛車21件に相振りの面を足す」のが先。新規エントリは中飛車左穴熊だけ（A）。**

1. **against.furibisha を全件に足す**（現状は九間飛車のみ）。文献の序列「向かい＞三間＞四間＞中飛車」（鈴木大介。[[wj-aifuribisha]]）に沿った案:
   向かい飛車 good／三間飛車 good／石田流 good／四間飛車 ok／中飛車 ok（左穴熊を組むなら good）／ゴキゲン ok／九間 good（収録済み）。ng は付けない（出典は「分が悪い」までで、×と言い切る記述は無い）。
2. **pairings に相振り囲いを足す**（why と出典付き。best は出典必須）:
   - mukaibisha: kinmusou（best）、migiyagura（best）を追加。mino は best のまま（コラムが向かい飛車＋美濃を基本例にしている）。「相手が向かい飛車だと自分の美濃は2筋の攻めに弱い」（藤井猛）は相手の戦法との相性なので、囲いの pairings ではなく戦法側の desc／againstTactic で扱う（[[wj-aifuribisha]]）。
   - sankenbisha・ishida: mino（best のまま。三間には相性が良い）、migiyagura は **ok**（右矢倉相手に三間飛車は相性が悪いと書かれるが、これは「相手が右矢倉」の話。自分の囲いとしては ok で足りる）、furibisha-anaguma-48kin（ok）。
   - shikenbisha: migiyagura（ok。矢倉相手に四間が効く＝§1-2）。
   - nakabisha: nakabisha-hidari-anaguma（best。ただし新戦法 §5-1 に移す）、mino・katamino は現状維持。
3. **COMBOS（定番セット）に相振りを足す**。`vs` を付ければ「相手＝振り飛車」のプリセットになる:
   `mukai-kinmusou`（向かい飛車＋金無双。named:false、basic:true 候補）／`mukai-migiyagura`（向かい飛車＋右矢倉）／`nakabisha-hidari-anaguma`（中飛車左穴熊。named:true）／`sanken-anaguma-ai`（三間飛車＋相振り穴熊4八金型。戸辺流の入口。named:false）。下書きは §5-3。
4. **周期表**: 新セルは「飛56」（5筋列、中飛車58・風車59の隣）の1つだけ。相振り向かい飛車を足す場合は variantOf mukaibisha で飛88に束ねる（新セルなし）。
5. **ratings**（`tactic-ratings.js`）: 中飛車左穴熊 = attack 3, speed 2, flex 2, safety 5, easy 3 を目安にする（pace: slow と矛盾させない）。【主観値。出典なし】
