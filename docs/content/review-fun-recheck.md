### 3-2 src フィールドの設計案

**方針: 既存の `[[ref]]` には合わせず、`src` を別に持たせて番号なしの 1 行で出す。** 理由:

1. `[[ref]]` は `rich(text, citer)` がパネル 1 枚ごとの連番 `[n]` に変え、末尾の「出典」節が同じ番号で並べ直す仕組み（js/ui/detail-sections.js 冒頭、js/core/html.js）。お楽しみは「もう一つ」で内容が入れ替わるため、番号が動いて出典節と食い違う
2. 「もう一つ」ボタン（js/ui/board-detail-view.js）は `textContent` で差し替えるので、本文中のトークンを解釈しない
3. `validate.js` の `cites()` は「そのエントリの `sources` に宣言した ref だけ」を検査する設計で、fun.js には `sources` 配列がない
4. お楽しみの項目は 1〜2 文・出典 1〜2 件なので、番号より直接リンクのほうが読みやすい

**UI（js/ui/detail-sections.js）**: 出典の 1 行を作る関数を足し、格言の描画を 1 か所にまとめる。

```js

  const srcLine = src => {
    const links = (src || []).map(s => K.SOURCES[s.ref]).filter(Boolean)
      .map(s => `<a href="${esc(s.url)}" target="_blank" rel="noopener">${esc(s.title)}（${esc(s.publisher)}）</a>`);
    return links.length ? `<small class="fun-src">出典: ${links.join(' / ')}</small>` : '';
  };
  const proverbHTML = pv => `<b>「${esc(pv.t)}」</b><span>${esc(pv.n)}</span>${srcLine(pv.src)}`;

  // K.detailSections に proverbHTML を追加で公開する
```

「もう一つ」（js/ui/board-detail-view.js、`.fun-shuf` のクリック処理）は、`textContent` の 2 行代入をやめて `proverbHTML` で丸ごと入れ替える（出典の行も一緒に変わる）。**ついでに既存の不具合が 2 つある**（コードの読みで確認。実機の操作は未確認）:

```js
  /** お楽しみ（fun.js）: proverbs / memes は t・n・src(登録済みの ref)が必須。videos は t・n と YouTube 検索の u */
  function fun(F, ctx) {
    const r = result();
    for (const [name, needSrc] of [['proverbs', true], ['memes', true], ['videos', false]]) {
      const list = F && F[name];
      if (!isArr(list) || !list.length) { r.errors.push(`${name}が空または配列でない`); continue; }
      const seen = new Set();
      list.forEach((x, i) => {
        if (!x || !isStr(x.t) || !isStr(x.n)) { r.errors.push(`${name}[${i}]にt/nがない`); return; }
        if (seen.has(x.t)) r.errors.push(`${name}[${i}]が重複: ${x.t}`);
        seen.add(x.t);
        if (needSrc) {
          if (!isArr(x.src) || !x.src.length) r.errors.push(`${name}[${i}](${x.t})にsrcがない`);
          else for (const s of x.src) if (!s || !ctx.SOURCES || !ctx.SOURCES[s.ref]) r.errors.push(`${name}[${i}](${x.t})の出典が未登録: ${s && s.ref}`);
        } else if (!/^https:\/\/www\.youtube\.com\/results\?search_query=/.test(x.u || '')) r.errors.push(`${name}[${i}](${x.t})のuがYouTube検索のURLでない`);
      });
    }
    return r;
  }
```

`all(ctx)` では `ctx.FUN` があれば `results.push({ kind: 'fun', id: 'FUN', ...fun(ctx.FUN, ctx) })` とし、`used` の集計に proverbs・memes の `src[].ref` を加える（足さないと、fun.js だけが使う出典に「どこからも参照されていない」警告が出る）。`tools/validate-castles.js` の `K.validate.all({...})` に `FUN: K.FUN` を渡し、`Kakoi.validate` の公開に `fun` を足す。
