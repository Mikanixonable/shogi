# デザイン規則 — 「墨と余白」

このアプリの UI は design-refs 01「墨と余白」を哲学とする。
和紙の生成りに墨と朱だけ。面・影・透過を捨て、**1px の罫線・余白・タイポグラフィの緩急**で格を出す。

## 1. 色（css/theme.css のトークンだけを使う）

| トークン | 意味 | 用途 |
|---|---|---|
| `--bg` `--fg` `--fg2` `--muted` | 地・墨・墨色・薄墨 | 背景・本文・見出し・補足 |
| `--line` `--line-2` `--faint` | 罫線（薄→中→最薄） | 区切り・枠・極薄の下地 |
| `--accent` | 朱 | **選択中・確定**の印だけに使う。装飾に使わない |
| `--good` `--bad` | 利きの緑・朱 | 相性 ◎/✕・両立しないの印 |
| `--f-*` `--t-*` | 系統色（和のくすみ色） | 囲い系統・戦法の主役駒の区別 |
| `--wood-*` `--piece-*` `--gote-ink` | 盤・駒・後手の青墨 | 盤面まわりのみ |

- 新しい色は足さない。必要なら既存トークンの `color-mix` で作る
- フォーカス輪は墨 2px（`:focus-visible`）。朱は状態の印なのでフォーカスには出さない

## 2. 状態のマトリクス（全コンポーネント共通）

| 状態 | 表現 |
|---|---|
| 既定・導出（implied） | 45°の網掛け＋破線。✕は付かない。押すと確定になる |
| 明示（selected slot） | 実線の胞。右上に ✕（外せる） |
| 選択中（detail を表示中） | 朱の輪郭（`.sel`）＋側ラベル強調 |
| 両立しない（ng） | 群れごとずらして傾け＋ひび＋✕と理由 title。自動では差し替えない |
| 相性（mark） | 河の共有辺に緑（◎）／朱（✕）の目地。共有辺が無い戦法は胞の縁に短い印 |
| 空き枠 | 「＋駒」の薄いドミノ。押すとその系統の一覧を開く |
| disabled | `--muted` 化＋`not-allowed`。消さずに残す |

## 3. 制約フィールド（js/ui/constraint-field.js）

- 1枚の SVG に両側を六角グリッドで描く。上段=相手（文字は180°回転＝盤と同じ向き）、下段=自分
- 行: `Y_TACTIC`（opp=0 / me=4）、`YCastle(who,r)`（opp=1+(2−r) / me=5+r）
- 左端=戦型の大きな胞（導出値・押すと情報）＋側ラベル、右=囲いポリへックス＋戦法ドミノ
- 河の左端に関係ラベルのピル（`#相居飛車` など）、「＋相手」の幽霊胞
- 側リセット `.cf-clear` は帯の右端に半分乗せる（`left: (W−26)/W`）
- viewBox は内容に応じて動的に切る（`this._view={y0,h}`）。相手 OFF 時は畳んで半分の高さ
- 操作は透明な `.cf-hit` ボタンの重なり（roving tabindex・Delete/Backspace・title）

## 4. 詳細（読む面）

- タブで分けない。概要 → 評価（五芒星）→ ハッシュタグ → 攻め筋 → 組み合わせ → 出典 → お楽しみ、を1連で
- 出典は `[n]` の連番。本文中 `sup.cite` と対応行を双方向に強調
- メタ情報（型・戦型・急戦など）は `#` ハッシュタグ。ボタンに見える枠は付けない
- お楽しみは読み物の余白として末尾に。格言＝朱の二重罫の引用、一覧＝`<details>` に畳む

## 5. モバイル（max-width:979px）

- `body[data-mtab]`（pick/read）で面を1枚だけ出す。下端 `.mtabs`＋横スワイプで切替
- スワイプ: 方向ロック（`LOCK=12`px・横>縦×1.4 で横と決定）→ `preventDefault` で縦混入を防ぐ → 指に追従 → `SWIPE_PX=72` または `FLICK_V=0.4`px/ms で確定。端は 0.26 のゴム紐
- スワイプ切替ではスクロール位置を動かさない（`via:'swipe'`）
- 盤は `.stage` に sticky。ドックへ下へ流れる（y>90 かつ下向き）と自動で畳み、上端（y≤8）で戻す。手動の `#boardToggle` は上端に戻るまで優先
- `.rail` `.detail` は `touch-action:pan-y`、`.app` は `overflow-x:clip`
- タップ目標は実効 44px 以上（六角胞など幾何の制約がある場所は警告として許容）
- 戦法リストは「筋の札＋名前＋記号」の縦リスト。9列グリッドに押し込まない

## 6. 動き

- `var(--ease)` = `cubic-bezier(.4,0,.2,1)`。滑り込みは `mdir` で向きを付け `animationend` で外す
- `prefers-reduced-motion` では全アニメ・トランジションを殺す（theme.css で一括）
- 遊びは控えめに：ゴム紐・駒の滑り・格言の引き直し程度。派手な演出は入れない
